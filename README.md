# 🧩 Meus Projetos Pessoais — Derick Eduardo

Bem-vindo ao meu espaço de projetos pessoais!  
Aqui estão reunidos meus **estudos práticos, experimentos e sistemas autorais** desenvolvidos durante minha trajetória no curso de **Análise e Desenvolvimento de Sistemas (PUC Minas)** e em projetos independentes.

Cada projeto tem como objetivo **aprender, testar novas ideias** e aplicar conceitos de **programação, lógica, banco de dados e desenvolvimento web**.

---

## 🚀 Objetivos dos meus projetos
- Praticar **Node.js, C# e SQL** em situações reais  
- Criar **mini sistemas funcionais** que simulam demandas do mercado  
- Aprender integração entre **front-end e back-end**  
- Evoluir minha **lógica de programação e arquitetura de software**

---

## 💡 Destaques dos Projetos

### 🧾 **Sistema de Login e Cadastro**
Sistema simples feito em **Node.js + MySQL**, com autenticação e CRUD de usuários.  
📂 Conceitos: Express, rotas, conexões, validação de dados.

---

### ✅ **Lista de Tarefas (To-Do List)**
Aplicativo de tarefas com **cadastro, edição e exclusão**, usando **Node.js e Bootstrap**.  
📂 Conceitos: CRUD completo, rotas REST, conexão MySQL, interface intuitiva.

---

### 🌍 **Timezone Converter**
Aplicativo que converte fusos horários de diferentes países.  
📂 Conceitos: manipulação de datas, consumo de API, layout responsivo.

---

### 📊 **DoeMais (Projeto Social)**
Plataforma acadêmica que conecta **empresas doadoras e ONGs**, permitindo a gestão de doações.  
📂 Conceitos: arquitetura MVC, banco relacional, validação de formulários, UI/UX.
